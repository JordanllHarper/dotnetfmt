# dotnetfmt

A whitespace formatter for C#, resembling `dotnet format whitespace`.

**Work in progress.** Only a subset of C# is recognized — see
`FUTURE_IMPROVEMENTS.md` for known gaps. Anything the parser doesn't
recognize is left untouched rather than mis-formatted.

This project is primarily generated by Claude, as an exercise in
learning to work with agentic coding tools — not a production-ready
tool.

## Usage

```sh
dotnetfmt file <path>
```

Formats a single `.cs` file in place, using indentation settings from
a nearby `.editorconfig` if present.

`dotnetfmt workspace [--workspace <path>]` (format every `.cs` file
under a directory) is planned but not yet implemented.
